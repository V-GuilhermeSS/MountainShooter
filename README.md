# 🎮 MountainShooter

A game developed in **Python**, created as part of the **Applied Programming Language** course project.  
The goal of this project is to apply programming concepts, logic, and game development in a practical environment.

---

## 🚀 About the Game
**MountainShooter** is a simple and fun game where the player interacts in a mountain scenario with shooting mechanics.  
It was designed to consolidate knowledge in:
- Python programming structures
- Graphics and event handling
- Game logic and interactivity

---

## 🛠️ Technologies Used
- **Python 3.x**
- **Pygame Library** (for graphics, sounds, and event handling)

---

## 📂 Project Structure
- `main.py` → Main game file
- `assets/` → Images, sounds, and other resources
- `README.md` → Project documentation

---
